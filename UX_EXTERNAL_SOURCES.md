# External UX sources used in MOO review

## Telegram Mini Apps official documentation

URL: https://core.telegram.org/bots/webapps

Applicable findings: Telegram states that Mini Apps should be responsive and mobile-first; interactive elements should mimic existing Telegram UI style, behavior and intent; animations should be smooth; inputs and images should have accessibility labels; apps should respond to dynamic Telegram themes; and content must respect safe area and content safe area to avoid overlap with Telegram controls. The same documentation describes BottomButton/SecondaryButton and safe-area capabilities relevant to MOO's fixed cart, bottom navigation and CTA layering.

## Baymard — Checkout UX 2025

URL: https://baymard.com/blog/current-state-of-checkout-ux

Applicable findings: Checkout friction can cause abandonment; guest checkout should be prominent; delivery information should answer when the user will receive the order rather than forcing calculations; order summaries and unexpected fees should be clear. Used only as directional UX evidence, not as a direct forecast for MOO conversion.

## Nielsen Norman Group — The Mobile Checkout Experience

URL: https://www.nngroup.com/articles/mobile-checkout-ux/

Applicable findings: mobile cart should be quickly accessible; users should be able to change quantities and remove items directly; checkout should prominently expose order summary and fees; mobile forms should minimize typing and use appropriate keyboards; delivery/pickup options and total cost should be clear before commit.
